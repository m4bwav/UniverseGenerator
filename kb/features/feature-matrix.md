# Feature matrix

Generated by `build_matrix.py` from 176 sources and 128 features (plus 5 features of our own that no surveyed generator has). Do not edit by hand: change `status.json` or the source reports and run the script.

Status: **have** = the game's generator does it today; **1.0** = in the first release; **1.x** = later, additive, no seed change; **rejected** = with the reason. Seeds: **yes** means adding it later would change what existing seeds produce, so it must be in 1.0 or behind a new generator version. Package: where the code or data lives under the D19 size budget (core = `UniverseGenerator`). Size: estimated added compressed size.

Totals: 58 1.0, 51 1.x, 16 have, 8 rejected.
